# CalendarBot (stub)

Заготовка под Telegram-бота. По текущей модели бота:

- Единственная функция бота — **запрос доступа** новым пользователем.
- Заявка уходит админу на подтверждение (регистрация через Telegram + уведомление админа).
- Никакого просмотра/редактирования событий в боте не будет.

Каркас (когда дойдём): отдельный процесс, ходит в тот же FastAPI-бэкенд
по HMAC-схеме (`X-Bot-Token` + подпись, заглушка в `CalendarServer/authorization.py`).
