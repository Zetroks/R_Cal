# CalendarWeb (stub)

Заготовка под веб-клиент. По текущей модели два режима:

1. **Публичный просмотр по ссылке** — ограниченный доступ к отдельным группам
   (ссылка с ключом, full/restricted), без учётной записи.
2. **Полный режим** — как десктоп-клиент, по связке логин+пароль.

Оба режима — поверх того же FastAPI-бэкенда (`CalendarService` — общий контракт).
Без аккаунта десктоп-клиент запускать бессмысленно, веб в режиме 1 — можно.
